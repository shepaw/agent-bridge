================================================================================
KEY FINDINGS
================================================================================

ARCHITECTURE:
   - Monorepo structure (npm workspaces)
   - Express REST API on port 4000
   - Vite dev server on port 5173 (proxies to :4000)
   - Hash-based routing (no third-party router)
   - React hooks for all state management

SECURITY:
   - Strong encryption (AES-256-GCM) for credentials at rest
   - API never exposes credential values
   - Masked display in UI (e.g., "sk-ant***789")
   - File permissions 0600 (owner-only readable)
   - QR tokens are single-use with TTL

DATA MODEL:
   - Agent (Project) stores: id, label, engine, cwd, host, port, tunnel config
   - Status tracks: running, pid, startedAt, stoppedAt, lastResult
   - Credentials: 4 engines with engine-specific env vars
   - Tunnel: serverUrl, channelId, encrypted secret
   - Peers: Device fingerprint, label, addedAt, revocation

PATTERNS:
   - Sentinel values prevent re-transmitting unchanged secrets
   - Component composition from router → detail → modals
   - Try/catch/finally with busy + error states
   - Parallel data fetching for related resources

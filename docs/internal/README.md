# Internal / archival docs

This directory holds the audit, exploration, and delivery-tracking documents
produced during the initial documentation pass over the repository
(`AUDIT_*`, `*_EXPLORATION*`, `DELIVERY_SUMMARY.txt`, `START_HERE.md`, …).

They are kept for historical reference. **They are not the onboarding path** —
start from the repository root [`README.md`](../../README.md) instead. Some
details here may lag behind the code; when in doubt, trust the code and the
root-level docs (`README.md`, `SECURITY.md`, `CHANNEL_PROXY_GUIDE.md`,
`docs/deployment.md`).
